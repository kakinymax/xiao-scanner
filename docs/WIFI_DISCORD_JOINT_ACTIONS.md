# Wi-Fi版の切替・実機確認の共同対応票

2026-10-04。コード実装とPC検証はCodexで進め、ユーザーの実機操作・接続先の設定が必要な項目をここへまとめる。[検証記録](WIFI_DISCORD_VALIDATION.md)のPC確認と区別する。移行の共同対応は以前に完了しており、これは新版の稼働確認。

| 項目 | ユーザーが行うこと | Codexが行うこと | 状態 |
|---|---|---|---|
| 実機の接続・保全 | XIAO本体をデータ対応USBで接続。必要に応じBOOT/RESET操作 | ポート・同じ実機であることを確認し、増えたログを含む4MBを再保全・照合。新版と旧版のパーティションを比較 | 待ち |
| 新版への切替 | 必要なボタン操作、画面表示の確認 | 検証済みビルドを書き込み・検証。履歴や設定領域をまとめて消去しない。旧版の復元方法を保持 | 待ち |
| Wi-Fi・Webhook | 2.4GHz Wi-Fiの情報とDiscord WebhookをPC設定ツールへ直接入力 | 起動・Wi-Fi/NTP・温湿度・保存状態を秘密値なしで確認 | 待ち |
| 実通知 | 送信先のDiscordでメッセージを確認 | 手動確認、定期報告、閾値超過、復帰、一部復帰、再通知の間隔を確認。検証時だけ変えた条件は元へ戻す | 待ち |
| 通信断と復帰 | 温度計の通信を一時的に止め、戻す操作を協力 | 計測・ボタン・グラフが動き続け、復帰時に大量送信しないことを確認 | 待ち |
| 電源断と履歴 | 履歴保存後に本体を電源から外し、戻す | CRC付き保存の復元、日時・区切り・空白の表示、RTCからの時刻保持を確認 | 待ち |
| センサーの切断・復帰 | センサーの安全な接続操作を協力 | 取得エラー時も操作できること、通知・復帰を確認 | 待ち |
| 旧Webの運用終了 | 必要なら旧URL利用の有無を補足 | 新版稼働確認後に旧Web公開を案内へ切り替えるか終了。旧HTML・テスト・Git履歴を保管し、経過へ追記 | 新版確認後 |

初期値は[使い方](WIFI_DISCORD.md)に記載。接続情報をチャット、PR、検証ログにコピーしない。本体コードを読む必要はなく、ユーザーが操作する箇所はその時点で日本語で案内する。

実機の受入条件は、温湿度表示と各期間のグラフ、ボタン・ブザー、再起動後の保存復元、Wi-Fi/NTP、Discordの定期・異常・復帰通知、通信断中の継続と復帰時の連投抑制が使用環境で確認できること。未確認の項目をコンパイル成功だけで完了にしない。
