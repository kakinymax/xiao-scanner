# xiao-scanner

## 更新履歴 (Changelog)

### 2026-05-20

- CDN経由で読み込んでいる外部スクリプト(`jsQR`, `Chart.js`)に、改ざんを検知するための仕組み(Subresource Integrity / SRI)を導入しました。あわせて、Chart.jsのバージョンを特定のもの(4.5.1)に固定することで、予期せぬ変更によるサイト崩れやセキュリティリスクを防ぎました。

- 外部ファイル（Chart.js、jsQR）の安全な読み込み設定（バージョン指定およびSRIハッシュの追加）を行いました。

### 2025-02-09

- アニメーションのフレームごと（`tick`関数内）に行われていた不要なキャンバスサイズの計算を、カメラの映像サイズが変わったときのみ実行するよう最適化しました。

### 2024-05-20

- Geminiのサイトを新しい画面（タブ）で開く際、移動先のサイトから元のアプリの画面が操作されるのを防ぐための安全対策を追加しました。
