# xiao-scanner

## ファイルとフォルダの役割

このプロジェクトのファイルやフォルダは、システムを正しく動かすために現在の配置になっています。それぞれの役割は以下の通りです。

### 1. アプリの本体（動かすために絶対必要なもの）

- `index.html`: Webアプリの画面やメインの機能が書かれた一番重要なファイルです。
- `firmware/`: スキャナーなどの機械（マイコン）を動かすためのプログラムが入っているフォルダです。

### 2. プロジェクトの説明書・メモ（人間が読むもの）

- `README.md`: このファイルです。アプリの説明や、ファイルの役割、これまでの更新履歴が書かれています。
- `ISSUES.md`: 今後直すべき問題点などを一時的にメモしておくファイルです。

### 3. テスト関連（アプリが正しく動くか自動でチェックするためのもの）

- `tests/`: アプリの機能が正しく動くかを確認するための、テスト用プログラムが入っているフォルダです。
- `jest.config.js`: テストを自動で行うツールのための設定ファイルです。

### 4. 開発・システムの設定ファイル（裏側で動く仕組みのためのもの）

- `package.json` / `package-lock.json`: アプリの開発に必要な外部ツールのリストや設定が書かれたファイルです。
- `.gitignore`: プログラムの変更履歴に含めないファイルを指定するための裏方のファイルです。
- `.jules/`: AIアシスタントが作業内容や学習内容を記憶しておくための専用フォルダです。

## 更新履歴 (Changelog)

### 2026-05-21

- ファームウェア（マイコン用プログラム）にて、文字（日付・時間など）を組み合わせる処理で、定められた枠（バッファ）から文字がはみ出してしまう危険性を防ぐため、より安全な仕組み（`sprintf`から`snprintf`への変更）に切り替えました。これにより、予期せぬ動作や脆弱性のリスクを軽減しています。

### 2026-05-20

- 非エンジニアの方にも分かりやすいように、現在のファイルやフォルダの役割（アプリ本体、説明書、テスト用、設定ファイルなど）を解説する「ファイルとフォルダの役割」セクションをREADMEに追加しました。

- CDN経由で読み込んでいる外部スクリプト(`jsQR`, `Chart.js`)に、改ざんを検知するための仕組み(Subresource Integrity / SRI)を導入しました。あわせて、Chart.jsのバージョンを特定のもの(4.5.1)に固定することで、予期せぬ変更によるサイト崩れやセキュリティリスクを防ぎました。

- 外部ファイル（Chart.js、jsQR）の安全な読み込み設定（バージョン指定およびSRIハッシュの追加）を行いました。

### 2025-02-09

- アニメーションのフレームごと（`tick`関数内）に行われていた不要なキャンバスサイズの計算を、カメラの映像サイズが変わったときのみ実行するよう最適化しました。

### 2024-05-20

- Geminiのサイトを新しい画面（タブ）で開く際、移動先のサイトから元のアプリの画面が操作されるのを防ぐための安全対策を追加しました。
