=========================================================
XIAO ESP32C3 AI Data Collector - AI学習ガイドブック
=========================================================

このプログラムは、現在「AI学習用データ収集（サイレント・ロギング）」を実行中です。
1分刻みの温度・湿度・不快指数データを最大1ヶ月分（約4.4万点）、裏で静かに記録し続けています。

データが十分（1週間〜1ヶ月）に貯まったら、以下のステップで「未来予測AI」を実装してください。

---------------------------------------------------------
STEP 1: データの吸い出し（CSV化）
---------------------------------------------------------
1. Webデコーダー（PC/スマホのブラウザ）を立ち上げます。
2. 「全AIログを取得 (GET_AI_LOG)」ボタン（※今後HTML側に追加する機能）を押して、BLE経由で全データを一括ダウンロードします。
3. 数分〜十数分かかりますが、転送中はマイコンの電源が落ちないようプログラムされています。
4. ダウンロードしたデータを `ai_training_data.csv` などの名前で保存します。

---------------------------------------------------------
STEP 2: AIモデルの学習 (Python)
---------------------------------------------------------
PC上でPython環境（Jupyter NotebookやGoogle Colabなど）を開き、機械学習を行います。

【学習の流れの例案】
- 入力 (X): 過去2時間分のデータ (1分刻み120回 × 温・湿・DI)
- 出力 (Y): 1時間後の温度・湿度・DI
- 手法: Random Forest や 小規模な Neural Network

TensorFlow Lite や `micromlgen` などを使い、学習結果をC言語のヘッダファイル（例：`model.h`）にエクスポートします。

---------------------------------------------------------
STEP 3: マイコンへの「知能」の組み込み
---------------------------------------------------------
作成した `model.h` をこのマイコンプログラムに組み込み、予測機能を追加します。

1. `model.h` を xiao_env_ai_collector フォルダにコピー。
2. `xiao_env_ai_collector.ino` を開き、AI推論用のライブラリ（`EloquentTinyML`など）を追加。
3. `recordData` 関数の末尾や `loop` 関数内で、推論（Predict）を実行するコードを書きます。

【コードの挿入イメージ】
```cpp
#include "model.h"
#include <EloquentTinyML.h>

// 毎分、最新のデータをAIに入力して1時間後を予測
float input_data[360] = { /* 直近120回分の温・湿・DI */ };
float predicted_di = ml.predict(input_data);

// 予測結果に基づく処理
if(predicted_di > 80.0) {
    // 1時間後に熱中症アラートが出やすいため、画面に事前警告を出す
}
```

これらのステップを踏むことで、「ただの記録計」が「環境予測AIアシスタント」へと進化します！
